# Workforce Intelligence MVP

نسخة أولى: موقع + بوابة رفع + وكيل مستندات (Gemini) + لوحة تشغيل تجريبية.

## النشر المجاني (Vercel)
1. ارفع هذا المجلد إلى GitHub (أو اسحبه إلى vercel.com/new).
2. خذ مفتاحاً مجانياً من https://aistudio.google.com/apikey
3. في Vercel: Settings > Environment Variables أضف `GEMINI_API_KEY`.
4. Deploy. افتح الرابط وجرّب رفع فاتورة.

## ما يعمل / ما لا يعمل بعد
- يعمل: استخراج الحقول بنسبة ثقة، فحص العمليات الحسابية على الخادم، تأكيد بشري، عربي/إنجليزي.
- تجريبي: بيانات الموظفين والمستندات محفوظة في متصفحك فقط (localStorage).
- لاحقاً: Supabase (schema.sql في الحزمة)، تسجيل دخول وأدوار، واتساب/بريد، اعتماد المالك والشريك.
- ملاحظة: البوابة العامة مفتوحة لأي زائر، أضف حماية (Turnstile/تحديد معدل) قبل نشرها علناً.
